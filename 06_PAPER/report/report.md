## 摘要

本报告汇编 CE-QUAL-W2（二维横向平均水动力—水质模型；Cole & Wells, 2003）官方示例复现与后续方法学审计产物，围绕四个相互独立、但必须联立声明的评估条件展开：（1）变量溯源记录 VPR（Variable Provenance Record，输出文件/列名/断面 segment I / 层 layer K / 单位 / 派生链 / 时间支撑 / 配对容差）；（2）控制律状态（以 Bonneville 总溶解气体 TDG，Total Dissolved Gas 的目标控制器 TDGTA 为例）；（3）数值健康记录 NHR（Numerical Health Record，负表面层厚度回退、exit 0 是否掩盖警告、DLTINTER 状态）；（4）证据类型声明（对观测技能 vs 输出通道内部一致性）。

在同一套 CCIW（Cascade Island / Bonneville 尾水水质站）观测上，Bonneville 三口径给出窄带 R²（决定系数，Coefficient of Determination）约 0.5082–0.5512，而 NSE（Nash–Sutcliffe Efficiency，纳什效率系数）却为 -2.8044 / 0.5 / -2.7516：R² 最高的 C 口径恰恰是 NSE 最差之一。技能最好、β≈1、模拟峰值钉在约 120.1% 的序列只存在于控制器门控文件 <code>TDGTarget_output.csv</code>；TDGTA=OFF 时该文件消失，但 SYSTDG 仍把控制前快照写到 <code>TDG_output.csv</code>（ON/OFF 逐日相同），因此不能写成「物理量被删除」。

命题已推广：DeGray 同一 TSR（Time Series，时间序列输出）文件中表层 T2 对库容均温 Tvolavg 给出 R²=0.9027 而 NSE=-0.5855（α=0.346，β=0.608）；Columbia 溶解氧 DO（Dissolved Oxygen）断面 I=49 vs I=33 的 R²=0.6505 而 NSE=-1.4821。<strong>二者皆无独立观测，属于输出通道内部一致性，不是对观测技能。</strong> Long Lake 在官方 DLTINTER=ON 下负厚度计数为 5/4/1/5（DLTMAX@JDAY30 = 20/50/100/200 s），非单调；DLTINTER=OFF 后全为 0——故 NHR 是报告项，不是「减小时间步更不稳」定律。

库内 CCIW 与 2026 年下载的 DART 小时值配对 n=17805，MAE=0.026537%，|Δ|≤0.051 匹配率=0.994945；未见示例观测被实质性改写的证据。2016–2025 有效小时超 120% 比例为 21.2%，但<strong>无样本外 NSE</strong>（模型约到 2011）。 Columbia 湿段 SOD（Sediment Oxygen Demand，底泥耗氧）均值 0.876 gO₂/m²/d，落在 Almeida 扫描带内比例 89.5%，但是 DeGray 模板移植，非现场率定。 W5 文献审计：38 篇中可重建 VPR 仅 2/38（5.3%），全文获取 9/38，其余标 unknown。

## 研究背景与目的

水库与河口水动力—水质模型的「率定好看」并不自动等于「评估对象可比」。当论文只报告 R²，而不声明输出文件、断面、层、控制律与数值警告时，读者无法判断两个 R² 是否在比较同一数学对象。Benicio 等（2024）对 38 篇 CE-QUAL-W2 富营养化应用给出综述表 2 的 R² 轴（0.32–0.977），这恰好提供了一个可审计的文献对照面：若多数研究缺少 VPR，则跨研究比较这些 R² 在方法上一般不能成立。

本项目的目的不是重新发明 CE-QUAL-W2，而是在官方示例上把四类评估条件写清楚，并给出可复算入口：

- 创新点 1：R² 对「相关但尺度错了」的通道盲；NSE/KGE（尤其 α、β）会暴露。
- 创新点 2：最优 TDG 序列由 TDGTA 门控；关控制器后评估文件消失≠物理量删除。
- 创新点 3：NHR 应随技能一并报告；5/4/1/5 仅 DLTINTER=ON 的诊断，OFF 全 0。
- 创新点 4 / W7：可复现性与 SOD 量级检查；Columbia SOD 为移植参数。
- W4/W5/W6：DART 核对与超标频率、文献 VPR 审计、w2eval run-card 协议。

> **科学边界（贯穿全文）**  
> DeGray / Columbia 无独立观测 → 内部一致性；无样本外 NSE；SOD 非现场率定；W5 全文 9/38，其余 unknown；不要把 2016–2025 的 21.2% 超标写成预报技能。

### 评估指标定义

设观测（或对照序列）为 o_t、模拟（或另一通道）为 s_t，样本量为 n。本报告所有「对观测」数字均来自 Bonneville–CCIW 配对；DeGray/Columbia 的 ref 是另一输出通道，不是野外观测。公式以纯文本给出（报告为自包含 HTML，不加载 MathJax CDN）。

- R²：线性相关结构的决定系数。对 s′ = a·s + b 一类仿射变换不敏感，因此当 α、β 严重偏离 1 时仍可能「看起来不错」。
- NSE = 1 − Σ(s−o)² / Σ(o−ō)²。NSE&lt;0 表示比用观测均值预报更差。它惩罚幅度与偏差，是技能的主标尺之一。
- KGE = 1 − √[(r−1)² + (α−1)² + (β−1)²]，其中 α = σ_s/σ_o，β = μ_s/μ_o。变量误指认常通过 α（方差被平均压掉或被另一站放大）和 β（均值错位）暴露。
- PBIAS / MAE：总体偏高偏低与平均绝对误差；辅助解读，不单独替代 NSE/KGE。


### 配对与容差

较短序列驱动最近邻配对；缺失值阈约 −90。Bonneville A/C 口径容差 0.05 d，B/S 日尺度容差 0.6 d（与既有评估脚本一致）。CCIW 有效 TDG 并不覆盖全年：n=1614 落在 JDAY 40613.58–40681.54（约 2011-03-11 至 2011-05-18）。

### 图 1　TDGTA ON/OFF 多口径时间序列（全年与 CCIW 窗）

![图 1　TDGTA ON/OFF 多口径时间序列（全年与 CCIW 窗）](I:/Projects/20260810-CE-QUAL-W2/06_PAPER/figures/W3_tdgta_on_off_timeseries.png)

**背景与作用：** 背景与作用：本图是创新点 2（控制律门控）的主证据图。评估报告若只写「TDG R²≈0.5」，读者无法知道用的是尾水亨利换算、控制器门控文件、库内 TSR，还是 SYSTDG 控制前快照。把 TDGTA=ON/OFF 与多口径画在同一时间轴上，是为了回答三个可检验问题：（1）关掉控制器后，评估对象是否还存在；（2）峰值是否还能回到观测尾部；（3）「好看」的序列是不是只活在某一份条件输出文件里。全篇后面关于「物理量被删除」禁令、可达范围与泄流再分配的讨论，都应回到本图与表 1。

**怎么读（坐标轴 / 曲线 / 散点 / 直方图 / 热图）：** 怎么读：这是多面板时间序列图。横轴为模型儒略日 JDAY（或换算后的日历日），纵轴为总溶解气体饱和度 TDG（%）。请先在图中定位 CCIW 有效配对窗（约 JDAY 40613.58–40681.54，对应 2011-03-11 至 2011-05-18），因为表 1 的 n=1614 与全部技能数字都只在这个窗内成立；窗外曲线只能看形态，不能当配对技能。再比较：（a）各曲线相对观测的高低；（b）是否出现约 120% 的「平顶」；（c）ON 与 OFF 两列在同一口径上是否重合。全年面板用来看控制器再分配是否改变长期形态；窗内面板用来读技能相关的局部差异。

**每条曲线（或分量）含义：** 每条曲线含义：观测 CCIW——Cascade Island / Bonneville 尾水水质站地面真值参考。口径 A（c_wdo_76 + t_wdo_76 亨利换算）——由氮与溶解氧等派生出的尾水 TDG，物理派生链不依赖 TDGTarget 文件是否存在，但会间接受泄流再分配影响。口径 B（TDGTarget_output.csv）——控制器后的目标/门控序列：TDGTA=ON 时存在，OFF 时文件消失。口径 C（BON_tsr_1_seg40）——库内时间序列通道，ON/OFF 几乎不变，说明库内状态不被「删变量」。口径 S（TDG_output.csv 中的 TDG_TDG）——SYSTDG 写出的控制前快照；ON 与 OFF 逐日相同（MAE=0），因此绝不能拿 S 顶替 B。若某 OFF 面板缺少 B 曲线，那是文件缺失，不是绘图遗漏。

**能得出什么结论：** 能得出什么结论：技能最好、β≈1、配对峰值钉在约 120.1% 的序列只出现在 B；关掉 TDGTA 后 B 面板为空，但 S 与 C 仍在，A 仍可计算。因此正确表述是「评估所用的门控文件消失」，而不是「模型不再计算 TDG / 物理量被删除」。A 在 OFF 后峰值抬高、α 变差，说明控制器主要压缩的是 B 的方差结构与可达范围，并不是把亨利口径 A「修成」了更好的无条件预报。表 1 中 R² 窄带（约 0.508–0.551）与 NSE 大散（−2.80 / +0.50 / −2.75）必须与本图联读。

**通俗版结论：** 通俗版结论：把 TDGTA 想成大坝调度员。他可以改泄流计划，并在自己的专用报表（B 文件）里把气体「登记」到目标带（约 120%）。把调度员关掉以后，专用报表没了，但河里的气体过程（S/A/C）仍在计算。你若继续拿那份被裁剪过的报表去宣传「率定很好」，就是在评价一份有条件存在的文件，而不是在评价「模型是否还懂 TDG」。

**怎么读（坐标轴 / 曲线 / 散点 / 直方图 / 热图）：** 怎么读：散点图。横轴一般为观测 TDG（%），纵轴为某口径模拟或对照序列（%）。实线（或虚线）为 1:1 参考：点落在线上表示该时刻数值相等。点云沿对角线方向拉长但整体偏高/偏低 → 主要是 β 问题；斜率过陡或过缓、纵向离散过大 → 主要是 α 问题；上缘被水平「压平」→ 存在硬顶或软顶（本案例约 120%）。逐子图比较 ON/OFF × A/B/C/S；OFF-B 无点表示文件不存在。

### 图 3　KGE 分量分解（r / α / β）

![图 3　KGE 分量分解（r / α / β）](I:/Projects/20260810-CE-QUAL-W2/06_PAPER/figures/W3_tdgta_kge_decomposition.png)

**背景与作用：** 背景与作用：Kling–Gupta 效率（KGE）把「像不像」拆成相关 r、方差比 α、均值比 β。本图把创新点 1 的理论探针落到 Bonneville TDG：误指认或控制律改变时，坏往往坏在 α、β，而不一定坏在 r。它解释「为何 R² 差不多、综合技能却天差地别」。

**怎么读（坐标轴 / 曲线 / 散点 / 直方图 / 热图）：** 怎么读：分组条形图。横轴为口径（A/B/C/S 等）或开关组合，纵轴为分量数值；理想参考为 1。每一组通常有三根条：r、α、β。先看哪一根离 1 最远——那就是该口径技能损失的主因；再对比 ON 与 OFF：关控制器是否让 α/β 回到 1，还是让某一分量更差。

**每条曲线（或分量）含义：** 分量含义：r = corr(s,o)，只描述同涨同跌的相位/形状相关；α = σ_s/σ_o，模拟标准差相对观测标准差（起伏是不是一样猛）；β = μ_s/μ_o，模拟均值相对观测均值（整体偏高还是偏低）。ON-B：β≈1、α 略小于 1（方差被目标带压缩）。ON-A/C：α 可 >1.5，方差过大。OFF-A：α 进一步胀大时 KGE 下降——说明关控制器并不自动改善亨利口径。

**能得出什么结论：** 能得出什么结论：报告 KGE 分解比只报一个综合分更有诊断力。它告诉你该回去查派生链、控制律与文件名，还是单纯的相位相关问题。与表 1、时间序列图、散点图三者一致：B 的「好」是有结构条件的。

**通俗版结论：** 通俗版结论：相关像「节奏对不对」，α 像「音量起伏是不是一样猛」，β 像「整体音调是不是偏高或偏低」。三口钟只有都对准，综合评分才高；只听节奏对就打高分，会被封顶报表骗到。

## 分析与讨论

四条证据链应当合读，而不是拆成互不相关的「四个创新点口号」。变量误指认（W1）解释为什么跨论文 R² 需要 VPR；控制律门控（W3/W4）解释为什么同一名称的 TDG 仍可能不可比；NHR（W2）解释为什么 exit 0 不是数值清白证明；文献审计（W5）把前三者从个案升为报告规范动机。SOD（W7）则提醒：可复现运行起来 ≠ 现场过程已率定。

- 条件可比，而非绝对不可比：当且仅当 VPR、控制律、NHR、证据类型对齐时，技能数字才可并置。
- NHR 是报告建议（should），不是强制标准警察；本报告也未验证全部 17 例框架。
- W5 的 confirmed vs unknown 必须分开写：unknown 不是 no。
- 2016–2025 超标频率可讨论可达范围，不可冒充样本外预报技能。


## 主要结论

- Bonneville：同一 CCIW 上 R² 窄带、NSE 大散；最优序列在 TDGTarget 门控文件中；SYSTDG 快照仍在，故非「物理量删除」。
- DeGray / Columbia：内部一致性再现高 R² 负 NSE / 断面歧义；无观测则无 skill 表述。
- NHR：exit 0 可掩盖负厚度；5/4/1/5 仅 DLTINTER=ON；OFF 全 0；非普遍时间步定律。
- DART 核对支持库内观测未被实质性改写；无样本外 NSE。
- W5：VPR 可重建 2/38；表 2 确认技能 1/12；KGE=0；全文 9/38。
- Columbia SOD 量级落在 Almeida 带内，但是移植参数。
